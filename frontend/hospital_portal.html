⚠️ High-Frequency Polling Tips

                

                    
✅ Reuse your token — don't re-login every request

                    
✅ Send one Bundle per patient per request

                    
✅ Use xargs -P 4 to parallelize curl calls

                    
✅ Check HTTP 429 responses for rate limiting

                    
⚠️ Keep it at ~10 req/s max without load testing first
